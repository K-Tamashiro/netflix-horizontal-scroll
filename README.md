# 🎬 Netflix Alt+Wheel & MX MASTER Horizontal Scroll

Netflixの作品一覧（行・カルーセル）を、キーボードの **Alt + 縦ホイール** や **Logicool MX Master シリーズのサムホイール（サイドホイール）** で直感的に横スクロールできるようにする Tampermonkey / ユーザースクリプトです。

---

## ⚠️ 重要：操作方法・初期設定の変更点

最新のブラウザおよびマウスユーティリティ（Logi Options+等）の仕様変更に伴い、従来の「Shiftキー」から **「Altキー」** へ移行し、サイドホイールの推奨設定を更新しました。

### 1. キーボード操作が「Alt + 縦ホイール」に変更

* OSやマウスドライバが `Shift + ホイール` を勝手に吸収・変換してブラウザ側へ届かない現象を回避するため、確実に認識される **`Alt + 縦ホイール`** に変更しました。
* 通常の縦ホイール操作時は、ページ全体の縦スクロールを一切邪魔しません。

### 2. Logi Options+ 推奨設定（サムホイール）

MX Master のサムホイールで操作する場合、**ブラウザ個別設定でキーストローク（左右矢印キー）を割り当てる**ことで、最も確実・快適に動作します。

1. **Logi Options+** を起動
2. 対象アプリに普段お使いのブラウザ（Chrome / Edge 等）を追加・選択
3. **「サムホイール」** の設定を開き、**「キーストロークの割り当て」** を選択
4. 以下のように割り当てます：
   * **スクロールアップ（奥へ回す）**: `Right`（右矢印キー `→`）
   * **スクロールダウン（手前へ回す）**: `Left`（左矢印キー `←`）

## ✨ 主な機能

* 🎬 **最新 Netflix UI（Hawkins）完全対応**
  * React仮想DOMの合成イベントに完全追従し、ボタンを確実にキックします。
* 🖱️ **MX Master サムホイール直結**
  * サムホイールからの左右キー入力をカルーセルの横送りに直結。親指一本で軽快に操作可能です。
* 🚫 **縦スクロール混ざり（ブレ）の完全根絶**
  * クールダウン中の余波イベントも含めて縦スクロールを完全に抑止し、横送り中の視点ズレを防ぎます。
* 👁️ **ホバー拡大プレビューの安全な自動消去**
  * 作品カード拡大時でも、Reactツリーをクラッシュさせずにプレビューを安全に退避させ、操作不能になるのを防ぎます。
* ⚡ **Alt + 縦ホイールで高速移動**
  * 縦ホイールとAltキーの組み合わせで、レスポンス良くサクサク行移動が可能です。

## 📥 インストール方法

1. ブラウザに拡張機能 [Tampermonkey](https://www.tampermonkey.net/)（またはユーザースクリプト対応環境）を導入します。
2. 以下のリンクをクリックすると、インストール画面が開きます。
   * 👉 **[スクリプトをインストール](https://raw.githubusercontent.com/zebrasoft/netflix-horizontal-scrol/main/netflix-scroll.user.js)**
3. **「インストール」**（または「更新」）をクリックすれば完了です。

---

## 🚀 使い方

Netflix (`https://www.netflix.com/`) を開き、作品の行の上にマウスカーソルを乗せて操作します。

| 操作 | 動作 |
| :--- | :--- |
| **Alt + 縦ホイール** | カルーセルをレスポンス良く横スクロールします |
| **サムホイール（スクロールアップ: → / ダウン: ←）** | 親指一本で1ブロックずつピタッと横スクロールします |
| **通常ホイール（修飾キーなし）** | 通常通りページ全体の縦スクロールを行います |

* **v3.0**
  * NetflixのUI変更対応、慣性暴走防止クールダウン導入。
